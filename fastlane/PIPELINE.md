# App Store pipeline (Fastlane)

> Note: `fastlane/README.md` is auto-generated by Fastlane on every run — keep
> human docs here in `PIPELINE.md` instead.

Automates App Store Connect for QuickProtect: localized metadata, build upload,
and submission. macOS app, bundle id `com.cb.quickprotect`, team `K2LM9FSU6C`.

## One-time setup

1. **Fastlane** via Homebrew (`/opt/homebrew/bin/fastlane`). Reinstall: `brew install fastlane`.
2. **App Store Connect API key** — *Users and Access → Integrations → App Store
   Connect API → Generate API Key*. **Role must be `Admin`** — cloud signing
   needs certificate management, which App Manager cannot do. Download the
   `AuthKey_XXXX.p8` once; store it in `~/.appstoreconnect/`.
3. Copy `fastlane/.env.example` → `fastlane/.env` with `ASC_KEY_ID`,
   `ASC_ISSUER_ID`, `ASC_KEY_PATH`. `.env` and `*.p8` are gitignored.

## Source of truth

`APP_STORE_LISTINGS.md` (repo root) holds every localized listing. Editing it
and running `scripts/gen_appstore_metadata.py` regenerates
`fastlane/metadata/<locale>/` (with char-limit checks). Don't hand-edit the
generated `.txt` files.

Locale map (app token → ASC): en→en-US, de→de-DE, fr→fr-FR, es→**es-ES**,
nl→nl-NL, it→it, pt-BR→pt-BR. (Change es in the generator for es-MX.)

## Lanes (run from repo root, `LANG=en_US.UTF-8` silences a UTF-8 warning)

| Lane | What it does |
|---|---|
| `auth_check` | Read-only: verify API auth + print version states |
| `status` | Read-only: version states + recent build processing |
| `metadata` | Regenerate + push all 7 listings (no binary) — safe anytime |
| `build` | Archive Release + export a signed App Store `.pkg` (cloud signing) |
| `upload_build` | Upload an exported `.pkg` to App Store Connect (no submit) |
| `cancel_review` | Remove the current version from review (frees the slot) |
| `submit_v11` | Set version 1.1, push metadata, attach build 2, submit |
| `release` | build → upload → metadata → submit (the going-forward one-shot) |
| `delete_stray_ios` | Cleanup: delete stray non-macOS editable version drafts |
| `gen` | Regenerate the Xcode project from project.yml |

## Gotchas (learned the hard way)

- **`platform: "osx"`** is required on every `deliver` call — it defaults to
  `ios` and will otherwise create a phantom iOS version / fail to find the build.
- The **Admin** key requirement above (cloud signing).
- After `cancel_review`, the version goes to `DEVELOPER_REJECTED` (editable),
  not `PREPARE_FOR_SUBMISSION` — that's normal for a self-withdrawn version.
- Screenshots aren't automated (the `screenshots/` dir isn't in deliver's
  `metadata/<locale>/` layout). Manage those in App Store Connect.
